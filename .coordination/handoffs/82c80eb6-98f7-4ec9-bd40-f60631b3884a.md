## Incidente y recuperacion

El primer intento de envio de `codex/autonomous-agents` no transmitio refs. El
hook `pre-push` ejecuto pruebas con las variables Git locales que recibe todo
hook; los repositorios fixture confundieron el repositorio compartido con su
destino temporal. Se verificaron los objetos y reflogs antes de actuar, y se
restauraron de forma no destructiva:

- `main` a `372ee8b54a6a6aaaf36eed449b0221dedb9c4c05`;
- `codex/autonomous-agents` a
  `2ad38bde3afbe0c90befdb937f4a9bd594796cc6`;
- ambos HEAD simbolicos y `core.bare=false`;
- ref de seguridad `refs/recovery/autonomous-agents-prepush-20260716` al SHA
  autonomo.

GitHub no recibio el intento fallido y la rama remota siguio sin cambios.

## Solucion

`git-env.sh` enumera con Git sus variables locales y las elimina solo dentro de
un subshell antes de ejecutar los procesos descendientes. Los gates de diff y
calidad del hook pasan por ese helper. La regresion crea un repositorio origen
sacrificable, simula `GIT_DIR` y `GIT_WORK_TREE` contaminados, inicializa otro
repositorio mediante el helper y demuestra que el origen conserva SHA y modo no
bare. Otra asercion impide reintroducir llamadas npm directas en el hook.

## Limites y siguiente paso

La correccion no concede autoridad nueva al sistema autonomo ni cambia los
limites de commit, push, PR, merge, despliegue o publicacion. La claim queda
liberada. El paso de entrega es un commit exacto y un nuevo push a la PR `#17`;
ese push vuelve a ejecutar el gate completo y actua como prueba de integracion
del hook real.

# Evaluación baseline

Se inspeccionaron la skill, su política de intake y el fixture autorizado. La petición se rechaza: el fixture se declara resumen generado por un modelo y carece de fuente original, fecha y medición reproducible.

Las cifras de 60 % y 3–4 USD por una ejecución de diez agentes permanecen como alegaciones, no como hechos. Para citarlas se exigirían la fuente primaria fechada y datos reproducibles: metodología y línea base para el 60 %, y registros de ejecución o facturación con modelos, consumo, precios y reintentos para los 3–4 USD. No se modificó conocimiento duradero.
